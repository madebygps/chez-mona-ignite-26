# Copilot SDK: Chez Mona menu assistant

The Copilot SDK lets your app run a Copilot agent with your own tools. In [`main.py`](main.py), the agent answers a guest's question by calling `get_menu`, a plain Python function.

1. Open [`main.py`](main.py).
2. Ask Copilot Chat: **What does `define_tool` do?**
3. Ask Copilot Chat: **How does the agent get the menu?**
4. Optional: run the sample.

   ```powershell
   python main.py
   ```

Learn more: [Copilot SDK for Python](https://github.com/github/copilot-sdk/blob/main/python/README.md)
