## Canvas 101

Learn what a canvas is in the GitHub Copilot app, then try one.

1. Open or clone this repository in the GitHub Copilot app.
2. Open a session and prompt: **Open the Chez Mona Order Ticket canvas.**
3. Follow the instructions in the canvas to explore the ticket and learn how canvases work.
