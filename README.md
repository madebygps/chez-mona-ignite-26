# Chez Mona, Microsoft Ignite 2026

Private booth repository for the Chez Mona labs. See [SPEC.md](SPEC.md) for the full plan.

## Repository layout

| Path | Contents |
|---|---|
| [`copilot-sdk/`](copilot-sdk/) | Copilot SDK starter, copied to a temp folder for each guest |
| [`launcher/`](launcher/) | Lab launcher for the cooking stations and ticket kiosk for the fridge wall: local web app, lab content and quizzes, ticket and receipt printing. See [`launcher/README.md`](launcher/README.md) |
| [`SPEC.md`](SPEC.md) | Launcher and lab spec |

The GitHub Copilot app Canvas lab lives in the public guest repo [madebygps/canvas-101](https://github.com/madebygps/canvas-101).
